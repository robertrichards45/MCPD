# MCPD Portal Command Demo Script

## Objective
Demonstrate how the MCPD Portal modernizes operational workflows, improves supervisory visibility, and reduces administrative burden.

## Demo flow

### 1. Demo setup
- Load sample staffing and workflow data.
- Explain that no real operational data is being used.

### 2. Officer mobile workflow
- Open the officer mobile home page.
- Show law lookup.
- Start a larceny report.
- Enter parties and facts.
- Generate a draft narrative.
- Show suggested forms.
- Submit the packet.

### 3. Supervisor workflow
- Switch to Watch Commander or Desk Sergeant.
- Show pending reports.
- Return one report for correction.
- Approve another report.
- Show saved work and training status.

### 4. Specialized units
- Show K-9 dashboard.
- Show CVI dashboard.
- Show SRT readiness.
- Show AID investigation tracking.

### 5. Command overview
- Show operational dashboard.
- Show training metrics.
- Show workflow visibility.
- Show report queue metrics.

## Key talking points
- Centralized workflows.
- Reduced paperwork burden.
- Mobile-accessible operational tools.
- Improved command visibility.
- Faster field-to-report workflow.
- AI-assisted draft support with human review.

## Important clarification
The portal does not replace CLEOC. It organizes and accelerates the workflow leading into CLEOC.
