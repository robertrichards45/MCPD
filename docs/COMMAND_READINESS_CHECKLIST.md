# Command Readiness Checklist

Purpose: prepare the portal for a controlled leadership demonstration.

## Demo path
- Load sample data.
- Open the officer home page.
- Run a reference lookup.
- Start a sample report.
- Enter parties and facts.
- Generate a draft narrative.
- Attach suggested forms.
- Submit the packet.
- Review as supervisor.
- Show dashboard metrics.

## Must pass before demo
- No blank pages.
- No broken buttons.
- No real data in sample mode.
- Mobile layout is readable.
- Desktop layout is professional.
- All sample workflows complete.
- Draft AI text is clearly marked for human review.
- Demo banner is visible when sample data is active.

## Production note
A leadership demo is not the same as operational approval. Production use still requires hosting, access, records, security, and policy review.
